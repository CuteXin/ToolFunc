部署minio部分: 
新建文件: docker-compose.yml
填写以下内容:
```
version: "3.8"

services:
  minio:
    image: minio/minio:RELEASE.2025-04-22T22-12-26Z
    container_name: minio
    restart: unless-stopped
    command: server /data --console-address ":9001"
    ports:
      # S3 API
      - "9000:9000"
      # Web 控制台
      - "9001:9001"
    environment:
      # 自定义 root 用户名（最少 3 字符）
      MINIO_ROOT_USER: minioadmin
      # 自定义 root 密码（最少 8 字符）
      MINIO_ROOT_PASSWORD: minioadmin
      # 时区（可选）
      TZ: Asia/Shanghai
    volumes:
      # 把容器内 /data 映射到本地目录，数据落盘至此
      - ./minio-data:/data
    healthcheck:
      test: ["CMD", "mc", "ready", "local"]
      interval: 30s
      timeout: 20s
      retries: 3
      start_period: 10s
```

创建秘钥并给秘钥分配对应桶的权限且设置捅为公开(创建账户的时候直接给就不需要设置下方的配置文件)
桶权限示例代码:
```
{
 "Version": "2012-10-17",
 "Statement": [
  {
   "Effect": "Allow",
   "Action": [
    "s3:*"
   ],
   "Resource": [
    "arn:aws:s3:::替换为桶名称",
    "arn:aws:s3:::替换为桶名称/*"
   ]
  }
 ]
}
```

部署milvus部分: 
https://milvus.io/docs/zh/configure-docker.md?tab=component
下载页面的配置文件和安装文件并放在同一个文件夹下
配置文件: https://raw.githubusercontent.com/milvus-io/milvus/v2.6.7/configs/milvus.yaml
安装文件: https://github.com/milvus-io/milvus/releases/download/v2.6.7/milvus-standalone-docker-compose.yml
安装文件注释掉关于minio容器的配置,包括:
 - minio容器配置块
 - MINIO_ADDRESS
 - depends_on.minio
添加volumes配置
 - ${DOCKER_VOLUME_DIRECTORY:-.}/milvus.yaml:/milvus/configs/milvus.yaml
将minio所有配置写入milvus.yaml文件
示例: 
 - address: 192.168.1.2:9000
 - port: 9000(此处的两个端口都不是web端口而是api连接端口)
 - accessKeyID: 秘钥账户
 - secretAccessKey: 密钥密码
 - bucketName: 桶名称
 - rootPath: files(根目录，保持默认即可)
启动: docker compose up -d
现在你可以在你的minio中看到创建的一些文件 这代表部署成功
